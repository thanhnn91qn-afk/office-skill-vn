# Bộ tài liệu Office (tham chiếu)

Các file trong thư mục này bổ sung cho **`SKILL.md`** ở gốc repo `office-skill-vn`.

| File | Khi nào đọc |
|------|----------------|
| [SKILL.md](SKILL.md) | Luồng .pptx tổng quát, QA slide, ý tưởng thiết kế |
| [SKILL-POWERPOINT.md](SKILL-POWERPOINT.md) | Bản song song / PowerPoint (nội dung tương đương SKILL.md pptx) |
| [pptxgenjs.md](pptxgenjs.md) | API PptxGenJS, pitfall màu/shadow/bullet |
| [SKILL-WORD.md](SKILL-WORD.md) | docx-js, unpack/pack OOXML, tracked changes, bảng, TOC |
| [SKILL-EXCEL.md](SKILL-EXCEL.md) | openpyxl, pandas, công thức, mô hình tài chính |

**Lưu ý:** Một số đoạn trong các file gốc trỏ tới CLI/script ngoài repo (`extract-text`, `scripts/office/unpack.py`, `scripts/recalc.py`, `editing.md`, …). Trong môi trường chỉ có skill này, hãy thay bằng: giải nén ZIP (`.docx` / `.pptx` là ZIP), **python-docx**, **openpyxl**, **PptxGenJS**, pandoc hoặc LibreOffice nếu đã cài.

Công văn **hai bảng theo mẫu quy định** (tham chiếu NĐ 30): ưu tiên `../office_skill_cli.py` và `SKILL.md` gốc repo.
